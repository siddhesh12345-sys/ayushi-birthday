AYUSHI BIRTHDAY WEBSITE — QUICK START

1. Extract Birthday-Website.zip.
2. Open the extracted Birthday-Website folder in VS Code (File > Open Folder).
3. Add your photos to the images folder using the filenames in images/ADD_YOUR_PHOTOS_HERE.txt.
4. Add your permitted MP3 file to music/birthday-song.mp3.
5. Open js/script.js and change BIRTHDAY_DATE to Ayushi's birthday in YYYY-MM-DD format.
6. Install the VS Code extension "Live Server" by Ritwick Dey.
7. Right-click index.html and choose "Open with Live Server".
8. Test all five navigation links and the Music button.

PAGES:
index.html = Home
memories.html = Photo gallery
letter.html = Emotional letter
celebration.html = Cake and confetti
surprise.html = Final surprise

NOTE:
The starter date is 2026-12-05 as a sample. Replace it with the correct date.
The website uses Google Fonts online; it still works with fallback fonts offline.
